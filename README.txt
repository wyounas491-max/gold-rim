# Gold Rim — Luxury Eyewear Portfolio

A responsive university front-end portfolio concept built with HTML, CSS, Bootstrap 5 and a small amount of JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — luxury black-and-gold styling, responsive layout and hover effects
- `script.js` — scroll reveal animations and mobile navigation behavior

## Add your existing images
Put these exact image files in the same folder as `index.html`:
- `glasses.jpg`
- `waqar.jpg`
- `Black Aviator.jpg`
- `Gold Rimless.jpg`
- `Hex Optical.jpg`
- `Stark Aviator.jpg`

The image filenames are case-sensitive on some hosting platforms. If an image does not appear, check the spelling and extension.

## Run it
1. Open this folder in VS Code.
2. Keep the image files in the project root.
3. Install the VS Code extension **Live Server** if needed.
4. Right-click `index.html` and select **Open with Live Server**.

Bootstrap and Google Fonts are loaded from online CDNs, so an internet connection is needed for those resources. The website itself is a front-end portfolio demonstration. The prices are examples; no cart, order processing or payment system is connected.
